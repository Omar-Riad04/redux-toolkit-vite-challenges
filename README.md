# 10 Redux Toolkit Vite Challenges (No APIs)

Each numbered folder is a **standalone Vite + React + TypeScript + Redux Toolkit** starter project. All challenges use local data only, and each `README.md` provides the full assignment.

## Run any challenge

```bash
cd 01-shopping-cart
npm install
npm run dev
```

Repeat for each folder. Each app has its own package.json and Redux store.

**Note:** Projects are deliberately incomplete: you implement the requirements. `node_modules` is not included in the download to keep it small.
